Think Harder: Methodical investigation considering multiple causes and using systematic debugging

Investigation Approach:
- Analyze error messages, stack traces, and log files systematically
- Consider both obvious causes and less apparent underlying issues
- Check configuration files, environment variables, and dependency versions
- Examine recent changes that might have introduced the issue

Debugging Strategy:
- Use systematic elimination to narrow down root causes
- Check common failure points: database connections, network issues, permissions
- Analyze performance metrics and resource utilization patterns
- Consider both local environment and deployment-specific factors

Root Cause Analysis:
- Look for patterns in when/where the issue occurs
- Consider integration points and external service dependencies
- Check for version conflicts, missing dependencies, or configuration drift
- Evaluate both immediate fixes and preventive measures

Output: Systematic diagnosis with clear reasoning and actionable resolution steps
