Think Harder: Build maintainable React components following modern patterns and conventions

Development Standards:
- Use functional components with proper React hooks (useState, useEffect, etc.)
- Implement proper component composition and prop validation with TypeScript
- Follow React best practices for state management and side effects
- Apply consistent styling approach (CSS modules, styled-components, or Tailwind)

Code Quality Focus:
- Create reusable components with clear interfaces and responsibilities
- Implement proper error boundaries and loading states
- Use semantic HTML and ensure accessibility basics (alt text, proper headings)
- Handle form validation and user input appropriately

Performance & UX Considerations:
- Optimize re-renders with useMemo and useCallback where beneficial
- Implement proper data fetching patterns with loading and error states
- Consider responsive design and mobile-first approach
- Ensure good user experience with appropriate feedback and interactions

Output: Professional, maintainable React application following modern best practices
