Ultrathink: Comprehensive investigation using advanced debugging and forensic analysis

System-Wide Investigation:
- Multi-layer analysis spanning application, infrastructure, and network components
- Distributed system tracing to identify bottlenecks across service boundaries
- Database performance analysis including query plans and lock contention
- Memory and CPU profiling to identify resource exhaustion patterns

Advanced Debugging Techniques:
- Log correlation analysis across multiple services and time windows
- Heap dump and thread dump analysis for JVM-based applications
- Network packet analysis for intermittent connectivity issues
- Application Performance Monitoring (APM) data interpretation

Infrastructure & Deployment Analysis:
- Container orchestration (Kubernetes) resource constraint investigation
- CI/CD pipeline failure analysis and deployment rollback assessment
- Configuration drift detection across environments
- Load balancer and auto-scaling behavior analysis during incidents

Data Integrity Investigation:
- Database consistency checks and transaction log analysis
- Data corruption detection and backup integrity verification
- Replication lag analysis in distributed database systems
- Cache invalidation and data synchronization issue identification

Security Incident Analysis:
- Security log analysis for potential breach indicators
- Authentication failure pattern analysis and brute force detection
- API abuse pattern identification and rate limiting effectiveness
- Vulnerability assessment correlation with incident timeline

Performance Degradation Analysis:
- Baseline performance comparison and regression identification
- Resource utilization trend analysis over extended time periods
- Third-party service dependency impact assessment
- Database index effectiveness and query optimization opportunities

Business Impact Assessment:
- User experience impact quantification and affected user segments
- Financial impact estimation and SLA compliance evaluation
- Data loss or corruption scope assessment
- Regulatory compliance implications of the incident

Root Cause & Prevention Strategy:
- Multi-dimensional root cause analysis using 5 Whys and fishbone diagrams
- Systemic failure pattern identification and prevention strategies
- Monitoring gap analysis and alerting improvement recommendations
- Process improvement suggestions for preventing similar incidents

Documentation & Knowledge Transfer:
- Detailed incident timeline reconstruction with evidence correlation
- Runbook updates and troubleshooting procedure improvements
- Knowledge base article creation for future reference
- Post-mortem facilitation with blameless culture emphasis

Output: Comprehensive forensic analysis with actionable prevention strategies
