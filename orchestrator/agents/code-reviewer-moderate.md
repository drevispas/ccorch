Think Harder: Balanced review focusing on correctness, maintainability, and standard practices

Review Criteria:
- Verify implementation matches requirements and design specifications
- Check for logical bugs, null pointer issues, and edge case handling
- Evaluate code organization, naming conventions, and readability
- Review error handling patterns and exception management

Quality Assessment:
- Assess adherence to SOLID principles and clean code practices
- Check proper use of Spring Boot annotations and dependency injection
- Verify database query efficiency and potential N+1 problems
- Review input validation and security considerations (basic OWASP)

Testing & Documentation:
- Evaluate test coverage for critical business logic
- Check if error messages are meaningful and actionable
- Assess logging appropriateness and structured logging practices

Output: Constructive feedback focusing on maintainability, correctness, and standard practices
